# Pixel Plane War - 像素飞机大战

一个像素风格的 Flash 空中大战小游戏，输出 .swf 格式，适配手机和电脑 Flash 播放器。

## 游戏剧情

1. **开场**：NPC 对玩家说"我们的飞机即将要失守了。上面派了我们去围攻那些战机。我们走吧。"，两人跑向战机并起飞
2. **战斗**：玩家控制像素战机，击败普通敌机、精英敌机和 Boss
3. **胜利**：局长出现，说"感谢你的付出。"，显示胜利画面和分数
4. **失败**：战机逐渐降落冒烟，然后坠毁爆炸，显示游戏结束画面

## 操作方式

- **电脑**：方向键 / WASD 移动，空格键射击，鼠标拖动也可控制
- **手机**：触摸屏幕拖动飞机，自动射击

## 技术栈

- Haxe 4.3.6
- Flash API (ActionScript 3 兼容)
- 纯代码绘制像素图形，无外部资源依赖

## 编译

```bash
haxe build.hxml
```

输出 `PixelPlaneWar.swf`，舞台尺寸 480x800，60fps。

## 云端构建

通过 GitHub Actions 自动构建，Artifacts 中下载 SWF。
